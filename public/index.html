GitHub Integration Setup Guide

1 Register an OAuth App on GitHub

Go to GitHub's Developer Settings to register a new OAuth Application:

• Register Link: github.com/settings/applications/new
• Application Name: SCJ28 Task Manager
• Homepage URL: http://localhost:2800
• Authorization Callback URL: http://localhost:2800/api/github/callback

Click Register application, generate a Client Secret, and copy both values.

2 Configure Credentials in SCJ28

You can save your credentials easily using either of these two methods:

Option A: In SCJ28 Settings UI (Easiest)
Click Settings () in the top header, scroll to GitHub OAuth Application, paste your Client ID and Client Secret, and click Save Settings.
Option B: Edit local .env file
Open .env in your project root and set: 
GITHUB_CLIENT_ID=your_client_id_here
GITHUB_CLIENT_SECRET=your_client_secret_here

3 Connect Repository & Authenticate Account

1. Select a project from the sidebar and click Link GitHub Repo (enter owner/repository).
2. Click Connect GitHub Account to authorize your user account.
